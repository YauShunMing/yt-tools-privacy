Privacy Policy

Last updated: 2026-09-25

"Shunming Video Channel Manager" ("the tool") is a personal, internal application built and operated by Simon Yau ("the owner") solely to manage YouTube channels that the owner personally owns. It is not distributed to, or used by, any third party.

What data the tool accesses

The tool uses the YouTube Data API (via OAuth 2.0) to act on the owner's own YouTube channels. This includes uploading videos, setting video metadata and thumbnails, and adding or updating caption tracks. It only accesses data belonging to channels the owner has explicitly authorized via Google's OAuth consent screen. Use of YouTube API Services is also governed by the Google Privacy Policy.

How data is used

Data retrieved from the YouTube Data API (such as channel and video identifiers, upload status, and caption track metadata) is used only to operate the owner's own publishing workflow. It is not sold, shared, or disclosed to any third party, and is not used for advertising or any purpose unrelated to managing the owner's own channels.

Data storage

OAuth tokens and any cached metadata are stored locally on infrastructure controlled by the owner and are not transmitted to any third-party service beyond Google's own APIs.

Data retention and deletion

Tokens and cached metadata are retained only as long as needed to operate the tool, and are deleted if channel access is revoked or the tool is decommissioned. You can revoke this tool's access at any time via your Google Account permissions page.

Contact

Questions about this policy or the tool's data handling can be sent to shunmingyau@gmail.com.
